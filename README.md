# chatlog (챗로그)

## 설치

### 1. 클라이언트 확장 (깃허브 설치)
ST → 확장 → Install extension → 이 저장소 URL 붙여넣기

수동 설치라면 저장소 전체를:
```
SillyTavern/public/scripts/extensions/third-party/chatlog/
```

### 2. 서버 플러그인 (수동 필수)
서버 플러그인은 확장 설치 기능으로 안 들어갑니다. 직접 복사하세요:
```
server/  →  SillyTavern/plugins/chatlog/
```
`config.yaml` 에서 `enableServerPlugins: true` 확인 후 ST 재시작.

### 3. 설정
확장 탭 → chatlog
- 실리태번에서 현재 선택한 연결 프로필 자동 사용 (기본값, 체크 해제 시 수동 선택)
- 이미지 인증에 사용할 실리태번 Vertex 연결 프로필 선택
- 이미지 키·프로젝트 ID·리전은 선택한 프로필과 실리태번 설정에서 자동으로 읽음
- 이미지 모델은 챗로그에서 나노바나나 모델 중 별도로 선택
- 활동 시간대 / 게시 판단 주기 / 최대 게시 공백 / 댓글 지연
- 캐릭터 카드를 일상 생성의 최우선 근거로 사용
- 최근 채팅의 현재 관계와 공유된 사건을 캐릭터 일상에 반영
- 새 단톡 생성 시 연결된 페르소나들의 프사·이름 중 화면에 표시할 페르소나 선택
- 새 단톡 생성 직후 캐릭터 카드·연결 페르소나·메타데이터 일치 최근 채팅을 한 번 분석해 단톡 공통 관계도로 저장
- 이후 게시물·댓글·반응에는 저장된 관계 요약만 재사용해 반복 토큰 사용 절감
- 표시 페르소나 또는 캐릭터 연결 정보가 바뀌면 상단의 관계 새로고침 버튼으로 다시 분석
- 화면 표시 페르소나와 AI 관계 페르소나를 분리해, 각 캐릭터는 자신에게 연결된 페르소나의 설명·관계·사진을 참고
- 각 캐릭터의 연결 페르소나 이름·프사 메타데이터와 맞는 최근 채팅을 우선 선택
- 연결 페르소나가 없는 캐릭터는 단톡의 표시 페르소나를 기본값으로 사용
- 기존 단톡 상단의 페르소나 버튼으로 화면 표시 페르소나를 언제든 변경
- 유저의 행동·신체 상태는 유저에게, 캐릭터의 행동·신체 상태는 캐릭터에게 정확히 유지
- 사람이 등장하는 자동 게시 사진은 게시 캐릭터가 직접 찍은 셀카 구도로 생성
- 페르소나가 사진에 등장하면 페르소나 프사와 설명을 별도 인물 참조로 사용
- 현재 날짜·계절·시각에 맞춰 옷차림, 자연광, 식생과 주변 환경을 조정
- 계절만으로 비·눈 같은 정확한 날씨를 임의로 만들지 않으며 장소의 실제 기후 조건을 우선
- 사람 없는 풍경·음식·물건 사진은 일반적인 캐릭터 시점 스냅으로 생성
- 자동 이미지는 이미지 응답을 명시적으로 요청하고, 참조 이미지·간단 프롬프트·텍스트 외형 순으로 재시도
- 이미지가 끝까지 생성되지 않으면 사진 없는 게시물을 저장하지 않음
- 일시적인 생성 실패는 10분 → 30분 → 60분 간격으로 최대 3회 자동 재시도
- 서버가 꺼져 있던 동안의 과거 슬롯은 몰아서 생성하지 않고 건너뛴 뒤 현재 시각부터 재개
- 설정 화면에서 마지막 성공·오류, 대기/재시도 작업, 다음 판단 시각을 확인
- 캐릭터 댓글과 이모지 반응은 한 번의 JSON 생성으로 함께 처리해 호출 수 절감
- 캐릭터끼리도 설정한 확률로 댓글을 달며, 이모지 후보는 화면과 서버 모두 10종으로 통일

> 이미지 생성의 `responseModalities: ['Image']`는 Gemini의 이미지 전용 응답 요청 형식이므로 유지합니다.

## 강제 실행

### 슬래시 커맨드 (ST 채팅창)
| 커맨드 | 설명 |
|---|---|
| `/chatlog` | 챗로그 열기 |
| `/chatlog-run` | 대기 댓글 + 캐릭터 반응 + 캐릭터 컷 전부 지금 실행 |
| `/chatlog-run what=comments` | 대기 중인 댓글 작업을 즉시 실행 (묶인 이모지 반응도 함께 처리될 수 있음) |
| `/chatlog-run what=reactions` | 대기 중인 반응 작업을 즉시 실행 (미리 정해진 캐릭터 댓글도 함께 처리될 수 있음) |
| `/chatlog-run what=cut` | 캐릭터 컷만 지금 생성 |
| `/chatlog-run room=우리로그` | 특정 로그만 |
| `/chatlog-now` | 다음 슬롯 시각을 지금으로 당김 (1분 내 실행) |
| `/chatlog-local` | 대기 댓글을 브라우저에서 조용히 생성 (채팅 UI에 안 뜸) |
| `/chatlog-jobs` | 대기 중인 작업 목록 (콘솔에 표로 출력) |

### curl (터먹스에서 직접)
```bash
# 전부 지금 실행
curl -X POST http://127.0.0.1:8000/api/plugins/chatlog/force \
  -H 'Content-Type: application/json' -d '{"what":"all"}'

# 댓글만
curl -X POST http://127.0.0.1:8000/api/plugins/chatlog/force \
  -H 'Content-Type: application/json' -d '{"what":"comments"}'

# 다음 슬롯 당기기
curl -X POST http://127.0.0.1:8000/api/plugins/chatlog/force/now \
  -H 'Content-Type: application/json' -d '{}'

# 대기 작업 확인
curl http://127.0.0.1:8000/api/plugins/chatlog/jobs

# 자동 실행 성공/오류/재시도 상태
curl http://127.0.0.1:8000/api/plugins/chatlog/status

# 방과 게시물 데이터
curl http://127.0.0.1:8000/api/plugins/chatlog/state
```
포트는 ST 설정에 맞게 바꾸세요. ST에 인증을 걸어뒀다면 `-u 아이디:비번` 추가.

### 데이터 위치
```
plugins/chatlog/data.json       # 방 / 게시물 / 작업 큐
plugins/chatlog/settings.json   # 플러그인 설정
public/user/images/chatlog/     # 생성된 이미지
```
큐가 꼬이면 `data.json` 의 `jobs` 를 `[]` 로 비우고 재시작하면 됩니다.

## 저장 / 정리

- 게시물 하단 **저장** — 사진 파일 다운로드
- 게시물 하단 **보관** — 자동 삭제 대상에서 제외
- 하루로그 → **GIF 저장** — 같은 시간대에 올라온 사진을 한 장면 안에 나란히 배치한 실제 GIF로 내보내기
- 확장 탭 → **지난 기록 자동 삭제** — N일 지난 게시물·사진·하루로그 영상 일괄 삭제 (하루 한 번 자동, 또는 "지금 정리")

## v0.7.12 변경 사항

- 다른 캐릭터 게시물에는 연결 페르소나의 최근 채팅과 관계 정보를 넣지 않도록 분리
- 캐릭터 카드에 명시되지 않은 연애 관계·애칭·질투·소유욕 및 사진 속 인물 관계 추측 금지
- 게시·이미지·댓글의 아침·낮·저녁·밤 표현과 조명을 실제 기록 시각 및 계절에 맞춤
- 일상 사진과 셀카를 기본 50:50으로 선택하고 캐릭터 카드에 따라 최대 ±15% 보정
- 같은 캐릭터가 같은 사진 유형을 3회 연속 올리면 다음 게시물은 반대 유형으로 강제
- 일상 사진에는 인물 참조 이미지를 보내지 않고 사람 없는 후면 카메라 스냅으로 생성
- 사진 유형을 게시물에 저장해 댓글 모델이 사진 속 관계를 임의로 추측하지 않도록 보강
- 같은 날짜·시간대에는 캐릭터별 게시물을 한 건만 허용하고 예약·재시도·강제 실행 중복 차단

## v0.7.13 변경 사항

- 단톡 표시 페르소나를 실제 게시물·댓글 작성자로 고정하고 캐릭터별 개인 연결 페르소나와 완전히 분리
- 단톡 생성 시 전체 캐릭터 카드, 각 연결 페르소나, 메타데이터가 일치하는 최근 채팅을 한 번 분석해 관계도 저장
- 표시 페르소나와 각 멤버의 관계 및 캐릭터끼리의 명시적 관계를 모든 단톡 멤버가 아는 공통 정보로 적용
- 다른 이름의 개인 연결 페르소나와의 연애 관계가 단톡 표시 페르소나에게 옮겨지는 문제 수정
- 표시 페르소나·멤버 카드·연결 페르소나가 바뀌면 관계도를 오래된 상태로 표시
- 단톡 상단에 관계 새로고침 버튼을 추가해 필요할 때만 관계 분석을 다시 실행
- 관계 분석에 실패해도 단톡은 유지하고 버튼으로 다시 시도 가능

## v0.7.14 변경 사항

- 이미지 API 키·모델·프로젝트 ID·리전의 중복 입력란 제거
- 이미지 생성용 SillyTavern 연결 프로필 선택 기능 추가
- 이미지 생성 순간마다 선택한 프로필과 `secrets.json`을 다시 읽어 키 교체를 자동 반영
- Vertex Express 키와 Vertex 서비스 계정/OAuth 프로필을 모두 지원
- 프로젝트 ID를 서비스 계정 JSON, 연결 프로필, 프로필 엔드포인트, SillyTavern 전역 Vertex 설정 순서로 자동 탐색
- 저장된 이미지 프로필이 없으면 이미지 모델이 지정된 첫 번째 연결 프로필을 자동 선택
- 기존 v0.7.13 이하의 이미지 설정값은 데이터 호환을 위해 보존하지만 신규 이미지 호출에는 사용하지 않음

## v0.7.15 변경 사항

- 이미지 연결 프로필은 키·프로젝트 ID·리전 등 인증 정보에만 사용
- 연결 프로필에 저장된 텍스트 모델명과 `-preview` 모델명은 이미지 요청에서 완전히 무시
- 챗로그 설정에 나노바나나 이미지 모델 선택창과 직접 입력란 복원
- 기본 이미지 모델을 Vertex Express에서 검증된 `gemini-3.1-flash-lite-image`로 설정
- `gemini-3.1-flash-image`, `gemini-3-pro-image`, `gemini-2.5-flash-image` 선택 지원
- 이미지 모델 검사는 연결 프로필이 아니라 챗로그 이미지 모델 설정값만 대상으로 실행
- 챗로그 이미지 모델에 `-preview`가 들어오면 존재하지 않는 Vertex 경로로 요청하기 전에 차단

## v0.7.16 변경 사항

- 업로드 시트 중복 열기와 올리기 버튼 중복 전송 방지
